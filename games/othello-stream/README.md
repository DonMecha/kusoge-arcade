# Grok Bot オセロ実況配信

社畜ボット二人がオセロを打ち、ニコニコ風のコメントとスパチャが流れる実況配信パロディです。2026-10-11のハッカソンで作りました。

[ブラウザですぐ遊ぶ](https://donmecha.github.io/kusoge-arcade/games/othello-stream/)

`index.html` をブラウザで開けばローカルでも遊べます。依存パッケージやビルドは不要です。`file://` と GitHub Pages のどちらでも動きます。

- 画面下の入力欄に書くと、その文字が画面に流れます。
- キー `1` / `2` : 黒 / 白 にテスト用スパチャ（¥2,000〜5,000）。ゲージが ¥10,000 になると必殺技。
- キー `3` / `4` : 黒 / 白 への応援コメント。
- `M` : 全ミュート。`B` : BGMだけ ON/OFF。
- `?fast=1` で高速テスト。`?board=8` で 8×8 盤。

流れるコメントは同梱の `comments.json`（サンプル）です。15秒ごとに再読込します。`file://` では `index.html` 内の同じサンプルを使います。キャラクターのドット絵は `index.html` に埋め込んであります。
