# 現実歪曲プレゼン

スティーブ・ジョブズのプレゼン像を誇張した、約90秒の非公式パロディゲームです。レンガを「革命的な新製品」として発表します。

[ブラウザですぐ遊ぶ](https://mechanohime.com/play/reality-field/)

`index.html` をブラウザで開けばローカルでも遊べます。依存パッケージやビルドは不要です。

5幕で宣言を選び、タイミングを合わせて言い切ります。結果画面ではXへの投稿文を開く、テキストをコピーする、画像を保存する操作ができます。最高記録は端末内の `localStorage` にのみ保存します。

本作の台詞と製品はフィクションです。Appleおよび関係者との提携・承認はありません。AIを用いて制作しています。
